## 여는 방법

1. 압축을 풉니다.
2. VS Code 에서 **폴더째로** 엽니다 (파일 → 폴더 열기).
3. `.html` 파일을 더블클릭하면 브라우저에서 바로 열립니다.
   VS Code 라면 Live Server 확장을 쓰는 편이 편합니다 — 저장하면 화면이 바로 바뀝니다.
4. 고쳐 보고, 저장하고, 브라우저를 새로고침(F5)하세요.

**고쳐 보라고 드리는 파일입니다.** 망가뜨려도 괜찮습니다 — 다시 받으면 됩니다.

## 학습 목표

- 주소창에 주소를 치고 엔터를 누른 뒤 화면이 뜨기까지 무슨 일이 일어나는지 설명할 수 있다.
- 인터넷과 웹의 차이, 클라이언트와 서버의 역할을 구분해 설명할 수 있다.
- HTML·CSS·JavaScript가 각각 무엇을 담당하는지 비유를 들어 설명할 수 있다.
- VS Code와 크롬 개발자도구를 설치하고, 첫 HTML 파일을 만들어 브라우저로 열 수 있다.
- 학습사이트에 가입하고 한 학기 학습 흐름(강의→실습→퀴즈→시험→프로젝트)을 이해한다.
